#  ESP8266 Wi-Fi Анализатор с OLED дисплеем

Портативный анализатор Wi-Fi сетей на базе ESP8266 (NodeMCU V3) со встроенным 0.96" OLED дисплеем. Сканирует окружающие сети, отображает уровень сигнала, примерное расстояние, каналы, типы шифрования и мониторит подключенные клиенты в реальном времени через веб-интерфейс.

## ✨ Возможности

### 🖥️ OLED Дисплей (0.96" SSD1306)
- Отображает имя точки доступа, пароль и IP-адрес
- Показывает количество и MAC-адреса подключенных клиентов
- Обновление статуса в реальном времени каждые 3 секунды

### 🌐 Веб-интерфейс (Captive Portal)
- **Подключенные устройства** — MAC и IP-адреса всех клиентов, подключенных к точке доступа
- **Живой график сигнала** — график RSSI окружающих сетей в реальном времени (обновление каждые 2 секунды)
- **Отсортированный список сетей** — все видимые Wi-Fi сети, отсортированные по убыванию сигнала
- **Примерное расстояние** — оценка расстояния до каждой сети (модель log-distance path loss)
- **Канал и шифрование** — номер канала и тип безопасности (WPA/WPA2/Open)
- **Управление LED** — включение/выключение встроенного светодиода из браузера

### 🛠️ Технические особенности
- Captive Portal с авто-редиректом (Android, iOS, Windows)
- Фоновое сканирование сетей с кэшированием (без задержек при загрузке страницы)
- Замаскированное имя точки доступа (выглядит как обычный сетевой принтер)
- Цифровой пароль из 8 символов

## 🛠️ Требования к оборудованию

- **Плата:** NodeMCU V3 (ESP-12E) или любая ESP8266 со встроенным 0.96" OLED (SSD1306, I2C)
- **USB Кабель:** Micro-USB с поддержкой передачи данных
- **Питание:** Стабильные 5.0 В (до 500 мА в пиках)

## 💻 Требования к ПО

- [Arduino IDE](https://www.arduino.cc/en/software) (версия 1.8+ или 2.x)
- Пакет поддержки плат ESP8266
- Библиотеки (устанавливаются через Менеджер библиотек):
  - `Adafruit SSD1306`
  - `Adafruit GFX Library`
